# ReactFullStack

Aplicación de ejemplo creada con React, Vite y Bootstrap. Incluye una barra de
navegación, un catálogo de productos y un formulario de contacto con validación
en el navegador.

## Requisitos

- Node.js y npm

## Instalación y ejecución

En la carpeta del proyecto, ejecuta:

```bash
npm install
npm run dev
```

Abre en el navegador la dirección local que muestra Vite (normalmente
`http://localhost:5173`).

En Windows PowerShell también puedes usar `npm.cmd` si la política de ejecución
bloquea `npm.ps1`.

## Comandos útiles

- `npm run build`: genera la versión de producción en `dist`.
- `npm run preview`: sirve localmente la versión generada.
- `npm run lint`: revisa el código con Oxlint.

La guía `explicacion-codigo.txt` describe la estructura y el funcionamiento de
los componentes principales.
