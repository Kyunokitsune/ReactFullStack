GUIA DE LA TIENDA GAMER
=======================

La aplicación está hecha con React y Vite.

Estructura principal:

- src/main.jsx inicia React y carga Bootstrap.
- src/App.jsx declara las rutas de Tienda, Registro y Admin.
- src/components/Tienda.jsx muestra el catálogo, el carrito y la descarga Excel.
- src/components/Registro.jsx contiene el formulario de registro.
- src/components/Admin.jsx permite administrar productos y usuarios.
- src/data/products.js contiene el catálogo compartido por la tienda, el admin
  y el archivo Excel. Cada producto define nombre, categoría, precio, imagen y
  descripción.

IMAGENES DE PRODUCTOS
---------------------

Guarda las imágenes en public/productos/. Los nombres deben coincidir con las
rutas img de src/data/products.js, por ejemplo:

- public/productos/mouse-gamer.webp
- public/productos/teclado-gamer.webp
- public/productos/headset-gamer.webp
- public/productos/monitor-gamer.webp
- public/productos/silla-gamer.webp
- public/productos/microfono-gamer.webp
- public/productos/control-gamer.webp
- public/productos/mousepad-gamer.webp

Las rutas comienzan con /productos/ porque Vite sirve el contenido de public
desde la raíz del sitio.
